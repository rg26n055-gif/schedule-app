# Smart Schedule Coordinator

複数人の日程調整を、できるだけ少ない入力負担で行えるWebアプリです。

管理者がイベント名・期間を設定して専用URLを発行し、参加者がそのURLから参加可能日時を回答できます。  
回答結果はFirebase Firestoreに保存され、管理者だけが回答一覧や候補日時ランキングを確認できます。

## 開発の背景

複数人で練習日程を決める際、

- 候補日時が多いと回答が面倒
- 「まだ予定が分からない」時間も多い
- 回答後の集計に時間がかかる

という問題がありました。

そこで、

**「まず曜日 × 午前・午後・夜で大まかに回答し、必要な日だけ細かく修正する」**

という方式を採用しました。

これにより、細かい時間を最初からすべて入力する必要がなく、回答者の負担を減らせるようにしています。

## 主な機能

### 管理者

- Googleアカウントによるログイン
- イベント作成
- 開始日・終了日の設定
- 参加者用URLの自動発行
- 回答者一覧の確認
- 候補日時の自動集計
- 候補日時ランキング表示
- 回答受付の締切 / 再開
- イベントと回答データの削除

### 参加者

- 専用URLからイベントへ参加
- 名前の入力
- ○ 参加できそう
- × 参加できない
- ？ 未確定

の3段階で回答

- 曜日 × 午前・午後・夜による簡易回答
- 特定の日のみ詳細修正
- 複数の練習形式への回答
- 回答データの送信

---

## 日程入力の工夫

このアプリでは、最初からすべての時間帯を細かく入力する必要はありません。

まず、

- 月曜日 午前
- 月曜日 午後
- 月曜日 夜
- 火曜日 午前
- ...

のように、大まかな参加可能時間を回答します。

その回答をイベント期間内の実際の日付へ自動反映し、

「この日だけ予定が違う」

という場合のみ詳細カレンダーから修正できます。

---

## 候補日時ランキング

回答結果から、各時間帯を自動評価します。

現在は、

- ○：+3点
- ？：+0.5点
- ×：-4点

としてスコアを計算し、候補日時をランキング表示します。

また、

- 全員○
- ×なし
- ×1人

なども管理者画面で確認できます。
